# Chr0ma.cc Website

A responsive static website designed for GitHub Pages.

## Files

- `index.html` — website structure/content
- `style.css` — styling and responsive layout
- `script.js` — mobile menu, current year, and reveal animations

## GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload all three files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for deployment.

## Customize

Search `index.html` for these demo links and replace them:

- `https://sellauth.com/` → your actual SellAuth product/checkout links
- `https://discord.com/` → your Discord invite
- `mailto:you@example.com` → your real contact email

You can also change product names, prices, descriptions, and demo vouches directly in `index.html`.

## Theme

The primary blue theme is controlled near the top of `style.css` with variables such as `--blue`, `--blue-2`, and `--accent`.
